# Sukruth S — Personal Portfolio

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript. It is ready to deploy on GitHub Pages.

## Files

- `index.html` — page content and structure
- `style.css` — responsive dark/light visual design
- `script.js` — mobile navigation, theme toggle and active-section navigation
- `assets/Sukruth-AI-Data-Engineer-Resume.pdf` — AI & Data Engineering resume
- `assets/Sukruth-Full-Stack-Developer-Resume.pdf` — Full-Stack Developer resume

## Before publishing

1. In `index.html`, replace `YOUR_GITHUB_USERNAME` in the GitHub URL.
2. Replace `YOUR_LINKEDIN_USERNAME` in the LinkedIn URL with your actual LinkedIn profile slug.
3. Check your email and phone number.
4. Optional: add project repository/demo links if you want to make project cards clickable.

## Publish with GitHub Pages

1. Create a **public** repository named exactly `YOUR_GITHUB_USERNAME.github.io`.
2. Upload all files and folders from this project. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the deployment and visit `https://YOUR_GITHUB_USERNAME.github.io/`.

## Local preview

Open `index.html` in a browser. No build command or package installation is required.

## Notes

- This is a static website; it does not run a Python/Django backend.
- The site uses Google Fonts when internet access is available and falls back to system fonts otherwise.
- The profile avatar is initials-based because no profile photo was supplied.
